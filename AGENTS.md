# Guía de trabajo de la web

Antes de modificar esta aplicación, lee la [guía general del repositorio](docs/project-guide.md), que describe la finalidad, el tono, el diseño y las referencias visuales de Cuántica S.L.

**Es obligatorio leer completo y adherirse a [CONTRIBUTING.md](CONTRIBUTING.md) para trabajar en este repositorio**, también para cambios pequeños o de documentación. Sus reglas de ramas, commits, comprobaciones y autorización de merges se aplican a todo el repositorio.

## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.
