# Paleta Cuántica SL

Propuesta derivada del hero aprobado. Vista visual: `index.html`. Tokens listos para integrar: `tokens.css`. No aplicada todavía a la web.

- **Universo** `#050711`: Fondo principal y episodio.
- **Órbita** `#121D2D`: Tarjetas y secciones oscuras.
- **Polvo cósmico** `#2D3C53`: Bordes decorativos y divisores.
- **Azul Cuántica** `#73B5DB`: Botones, enlaces sobre oscuro y detalles.
- **Bruma** `#A8BCD0`: Texto secundario sobre oscuro.
- **Luz estelar** `#EDF4F8`: Fondos claros y texto principal sobre oscuro.

Los tres tonos oscuros proceden del fondo del frame 9. Azul Cuántica conserva el acento existente; bruma y luz estelar se ajustan para lectura. Botones azules con texto universo. En fondos claros usar texto órbita, no azul cielo.
